# 04 - UDS: Talking to ECUs and Diagnostics

Phase 3 was the network layer (raw CAN frames). UDS (Unified Diagnostic
Services, ISO 14229) is the layer above: the request/response protocol used to
interrogate and command a specific ECU - read data, reset it, and unlock
protected functions. Using OpenGarages' UDSim (a graphical UDS simulator built
to run alongside ICSim), I practiced the diagnostic attack workflow on a
virtual bus.
